# 输出格式模板

## 单条书证格式

```
### 书证N

**书名**：《XXX》
**作者**：XXX 主编
**出版社**：XXX出版社
**版次**：第X版
**出版年月**：XXXX年X月
**相关页码**：第XX-XX页
**读秀标识**：dxNumber=XXXXXXXXXXXX

**相关段落原文**（逐字引用）：
> "……[完整引用原文段落，保留原文标点]……"

**相关性说明**：该段落直接记载了……，与……高度对应。该书将上述……作为通用工艺参数记载，未附加任何特殊条件限定，足以证明……属于本领域的常规……选择。

**检索关键词**：`XXX`（命中X条）
```

## 多条书证汇总格式

```
## 使用建议

在审查意见中引用时，建议按以下优先级：

**首选书证X（作者XXXX，第XX页）**——[理由]。

**辅以书证X（作者XXXX）**——[理由]。
```

## 审查文书中的引用格式

公知常识证据不占对比文件编号，不与对比文件混排，按以下格式单独著录：

**著录格式**：
> 本领域公知常识证据N（《书名》，作者 等，出版社，第X版，第XX-XX页，YYYY年M月）

**正文引用句式**：
> 针对区别(…)，本领域技术人员知晓……（参见公知常识证据N（《书名》……著录项），该证据记载了："……"〔书页原文引用，加下划线〕），可见，在该证据给出的……启示下，……是本领域技术人员根据实际需要作出的常规选择，属于本领域的公知常识。

**著录格式规则**：
- 编号按正文首次引用顺序确定（证据1→证据2→证据3……）
- 不与对比文件混编
- 编者超过两人时只列第一人加"等"
- 出版日期后置，用"YYYY年M月"全称
- 段落引用标注页码（非段落号）
