# 输出格式模板

版本 v1.2 ｜ 更新 2026-11-06

## 单条书证格式

```
### 书证N

**书名**：《XXX》
**作者**：XXX 主编
**出版社**：XXX出版社
**版次**：第X版
**出版年月**：XXXX年X月
**相关页码**：第XX-XX页（命中摘录页第XX页）
**读秀标识**：dxNumber=XXXXXXXXXXXX

**相关段落原文**（逐字引用）：
> "……[完整引用原文段落，保留原文标点；直接支撑命题的关键条款不得截断]……"

**相关性说明**：该段落直接记载了……（对应命题X）、……（对应命题Y），与……高度对应。该书将上述……作为通用工艺参数/通用规则记载，未附加任何特殊条件限定，足以证明……属于本领域的常规……选择。

**检索关键词**（读秀正文检索·精确短语·实测）：`书证原句短语`——相关结果X条，目标文献排序第M（唯一命中时注明"唯一命中"）；备用精确短语：`短语A`、`短语B`。取证按短语检索直达第XX-XX页。
```

## 多条书证汇总格式

```
## XXX（待证明命题拆分：①…②…③…）——公知常识书证

### 书证1
[按单条格式]

### 书证2
[按单条格式]

### 书证N
[按单条格式]

---

## 命题覆盖与组合裁定

命题①：书证1（……）、书证2（……）交叉印证——充分。
命题②：书证1（……）单独覆盖——充分。
（未被书证覆盖的边缘命题：以常规说理收口；跨领域举证补桥接句。组合档位 A 档/B 档经用户明确裁定后闭合。）

---

## 检索关键词汇总（供复核查证）

1. `精确短语1`（相关结果1条，目标排序第1）——定位书证1。
2. `精确短语2`（相关结果1条，目标排序第1）——定位书证2。
3. `组合词`（命中N条）——候选线索，未作溯源关键词。
（注明已废弃关键词及原因。）

## 使用建议

在审查意见中引用时，建议按以下优先级：

**首选书证X（作者XXXX，第XX页）**——[理由]。

**辅以书证X（作者XXXX）**——[理由]。
```

## 溯源检索卡格式（供用户下载原文扫描）

组合裁定后，为每条正式书证交付溯源检索卡：

```
### 书证N 溯源检索卡

- 检索关键词（主词·精确短语·已实测）：`XXXXX`
- 命中情况：相关结果 X 条，目标文献排序第 M（唯一命中/排序第1）
- 检索模式：读秀正文检索（Field=all），机构 IP
- 取证页码：第 XX-XX 页（命中/引文落点第 XX 页）
- 读秀标识：dxNumber=XXXXXXXXXXXX（永久锚点）
- 直达阅读页参数：kid=…&pagenum=XX&epage=XX&spgno=XX（签名 timestr/a 有时效，过期后按主词重检复现）
- 备用精确短语：`短语A`、`短语B`
```

## 审查文书中的引用格式

公知常识证据不占对比文件编号，不与对比文件混排，按以下格式单独著录：

**著录格式**：
> 本领域公知常识证据N（《书名》，作者 等，出版社，第X版，第XX-XX页，YYYY年M月）

**正文引用句式**：
> 针对区别(…)，本领域技术人员知晓……（参见公知常识证据N（《书名》……著录项），该证据记载了："……"〔书页原文引用，加下划线〕），可见，在该证据给出的……启示下，……是本领域技术人员根据实际需要作出的常规选择，属于本领域的公知常识。

（跨领域举证时补桥接句：该规则属X、Y行业跨行业通用知识。）

**著录格式规则**：
- 编号按正文首次引用顺序确定（证据1→证据2→证据3……）
- 不与对比文件混编
- 编者超过两人时只列第一人加"等"
- 出版日期后置，用"YYYY年M月"全称
- 段落引用标注页码（非段落号）
